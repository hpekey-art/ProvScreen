# Data provenance and redistribution boundary

The MIT license applies to ProvScreen source code and original documentation. It does not change the legal status or terms of upstream U.S. EPA records.

This lightweight candidate contains derived, scoped event-hour tables, frozen reference tables, expected-output records, and a supplied Blackstone reconciliation ledger for reproducibility. It does not contain the original bulk CAMPD downloads, ECMPS Emissions Export JSON/ZIP collections, API credentials, or the original Rhode Island 2023 XML processing archive. Hashes of selected external raw inputs used in historical or local verification are recorded in `reports/RAW_SOURCE_SHA256.csv`.

The Massachusetts evidence is limited to Blackstone units 11/12 and Salem Harbor units 1/2. Blackstone CS2 denotes explicitly linked inherited shared-stack provenance; it is not evidence of independent unit-level measurement. Users obtaining upstream source files must review and comply with the provider's current access and reuse terms.
